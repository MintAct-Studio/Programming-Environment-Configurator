    官方提供压缩包的，AutoED 直接下载并解压到你的安装目录；只能装安装器的，给出官方地址。

    网络 · 日志 · 环境锁

    国内直连 GitHub 经常被重置。有代理就填上，版本查询和下载都会走它。

    出问题先「导出日志」，再点「解析日志文件」——常见报错会被认出来并给出处理办法。

    把当前环境存成一个文件。别人拿到它，就能装出和你一模一样的环境。
